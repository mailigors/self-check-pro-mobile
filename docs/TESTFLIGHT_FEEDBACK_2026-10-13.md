## Проверка на устройстве

Повторное тестирование с реальным аккаунтом на iPhone необходимо после установки новой сборки: сравнить число проверок со списком, открыть отклонения, пройти ввод полей и выбрать дату/время, проверить меню с системным размером текста и клавиатурой. Тесты API используют изолированный адаптер; они не подтверждают исправность серверных прав для каждого реального чек-листа.

Новая сборка в App Store Connect не загружалась. Для проверки на iPhone потребуется выпуск следующей TestFlight-сборки.

## Уточнения по повторной проверке

Ошибочное значение в поле теперь окрашивается красным, сообщение стоит непосредственно под полем, перед подсказкой границ и комментарием. Ошибки непустых сохранённых ответов проверяются при открытии; после сохранения локальная валидация объединяется с ответом сервера и не исчезает. Регрессионный тест проверяет цвет, расположение сообщения, сохранение, повторное открытие и исправление значения.

Ошибка перехода «Проверок за период» связана с отправкой дат без часового пояса. В локальном исходном коде бэкенда `ChecklistController.getChecklists` параметры имеют тип `OffsetDateTime`. Границы календарных дней устройства теперь преобразуются в UTC и отправляются с суффиксом `Z`; конец периода включает последний микросекундный момент дня. Формат подтверждён тестом исходящих API-параметров; повторный запрос с реальным аккаунтом в этой проверке не выполнялся.
