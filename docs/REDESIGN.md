# Редизайн SelfCheckPro

Визуальный ориентир: https://bkx4pgq2orzl4.kimi.page/

Обновлены вход, список чек-листов, запуск проверки, типы ответов,
итог завершённой проверки, профиль и общие компоненты интерфейса.
Шрифт Manrope включён локально вместе с лицензией OFL.

Новая проверка: объект контроля → шаблон → создание через существующий API.
Сохранение, обязательные поля, вложения, экспорт и возобновление работают
через прежние репозитории и контроллеры. Оценка берётся из API.
Счётчики соответствий и замечаний из демо не воспроизводятся: текущая модель
не предоставляет надёжных итогов такого вида. В списке не показывается
выдуманный прогресс: число ответов рассчитывается только в форме проверки.

Восстановление пароля и настройки уведомлений в макете не имеют продолжения,
а в приложении для них нет рабочего API-сценария. Неактивные кнопки не добавлены.
Данные пользователя и смена пароля доступны в профиле.

## Проверка

```sh
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn
```

`test/redesign_flow_test.dart` проверяет выбор объекта и шаблона с возвратом,
сохранение ответов, обязательные поля, завершение и возобновление, профиль и вход.
Ширина тестового экрана — 320 px; выбор проверки также проверяется
с увеличением текста до 140%.

## Локальное превью с демонстрационными данными

```sh
flutter run -d chrome --target tool/design_preview.dart
```

Чтобы начать с экрана входа:

```sh
flutter run -d chrome --target tool/design_preview.dart --dart-define=PREVIEW_LOGIN=true
```

Этот отдельный entrypoint использует фикстуры из `test/support/`.
Экспорт в превью использует PDF/XLSX-примеры с пометкой DEMO для проверки
сохранения и отправки. Загрузка вложений не подключена к серверу.
Обычный `lib/main.dart` продолжает использовать настоящий API.

## Подсказки при заполнении

Короткий и длинный текст показывают число символов, минимальную и максимальную
длину и полосу заполнения. Счётчик учитывает видимые символы, включая emoji.
Ввод за пределами длины сохраняется и выделяется цветом.
Числа, даты и даты со временем показывают обе границы; отсутствующая граница — `-`.
Для `double` границы в подсказке округляются до `precision` знаков после запятой
(по умолчанию 2); введённый ответ при этом не округляется.
Время отображается в локальном часовом поясе устройства.

Настройки вариантов принимаются из JSON-объекта, JSON-строки и старого
строкового представления карты. Поддерживаются строковые варианты и объекты
с `text`, `label`, `name`, `value`; подпись и отправляемое значение разделены.
`test/item_input_settings_test.dart` проверяет нормализацию настроек, живой
счётчик, границы и сохранение выбора в radio, checkbox и выпадающем списке.

## Сохранение и отправка отчётов

Кнопки PDF и Excel в списке и результате загружают настоящий отчёт через API,
затем показывают «Сохранить файл» и «Поделиться». Системное меню отправки
получает файл с его именем, MIME-типом и темой письма; пользователь выбирает
почту или другое приложение. Для iPad передаётся область кнопки.
В браузере используется Web Share API. Автоматическая загрузка вместо
отправки отключена: при отсутствии поддержки пользователь может явно
сохранить файл. Отмена меню не сообщает об успешной отправке.
